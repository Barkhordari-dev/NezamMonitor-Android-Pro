# NezamMonitor Android — مانیتور نظام مهندسی

> نسخه موبایل نرم‌افزار مدیریت هوشمند پرونده‌های نظام مهندسی

---

## 🎯 این برنامه چیکار می‌کنه؟

نسخه موبایل نرم‌افزار مانیتور نظام مهندسی هست. باهاش می‌تونید اطلاعات پرونده‌ها رو روی گوشیتون مشاهده کنید، توضیحات پیگیری رو ویرایش کنید و مستقیماً با مالکین پرونده‌ها تماس بگیرید.

## ✨ امکانات

| امکان | توضیح |
|-------|-------|
| 📋 پرونده‌ها | مشاهده و جستجوی تمام پرونده‌ها |
| 👷 مهندسین | لیست مهندسین هر پرونده |
| 💰 حق‌الزحمه | مشاهده وضعیت پرداخت و جمع‌بندی |
| 📄 گزارش‌ها | مرور گزارش‌های ثبت‌شده |
| 📌 پیگیری | ویرایش توضیحات با قابلیت ذخیره |
| 📞 تماس | شماره مالکین قابل کلیک |
| 📥 وارد کردن | انتقال اطلاعات از ویندوز |
| 📤 خروجی | ارسال تغییرات به ویندوز |

## 📥 دانلود

## 🚀 نصب و اجرا

1. فایل APK رو دانلود کنید
2. در تنظیمات گوشی: **امنیت** → **منابع ناشناخته** رو فعال کنید
3. APK رو نصب کنید
4. اولین بار: فایل `.nzmdata` رو از برنامه ویندوز وارد کنید

## 📋 نیازمندی‌ها

- **اندروید:** 8.0 یا بالاتر
- **حجم:** ~11MB
- **پیش‌نیاز:** فایل `.nzmdata` از برنامه ویندوز

## 🔗 ارتباط با نسخه ویندوز

```
ویندوز → خروجی → .nzmdata → اندروید → وارد کردن
اندروید → ویرایش → خروجی → .nzmdata → ویندوز → وارد کردن
```

**نسخه ویندوز:** [GitHub](https://github.com/mmahdib2020-cpu/nezammonitor-windows/releases)

## 📱 راهنمای سریع شروع کار

1. **روی ویندوز:** اطلاعات پرونده‌ها رو استخراج کنید
2. **روی ویندوز:** منوی «خروجی اندروید» → ایجاد فایل `.nzmdata`
3. **روی اندروید:** برنامه رو باز کنید → «ورود اطلاعات» → فایل `.nzmdata` رو انتخاب کنید
4. **تمام!** اطلاعات در گوشی شما قابل مشاهده است

## ⚠️ نکات مهم

- اولین بار حتماً باید فایل `.nzmdata` از ویندوز وارد کنید
- از اطلاعات خود پشتیبان‌گیری کنید
- تغییرات در پیگیری قابل انتقال به ویندوز هستند
- برای تماس: کافیه روی آیکون 📞 کنار شماره تلفن کلیک کنید
